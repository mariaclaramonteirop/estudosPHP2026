# estudosPHP2026

Repositorio de simulados para treinar para a P2 e PF de PHP, com foco em API, MVC e DAO.

## Objetivo
Treinar criacao de APIs em PHP, organizacao em MVC e acesso a dados com DAO (CRUD e prepared statements).

## Estrutura do repositorio
- 00_indice_geral.md: indice geral dos materiais.
- provas (exemplos abaixo; novas provas serao adicionadas):
  - prova_01_todo_basico.md
  - prova_02_pets_intermediario.md
  - prova_03_carros_avancado.md
  - prova_04_ecommerce_expert.md
- basico_01_pets_adocao.md
- gabarito_referencia.md
- Maria/ e Manu/: pastas para resolucoes e revisoes.

## Formato das provas
As provas serao adicionadas em arquivos .md ou .pdf.

## Como usar
1. Escolha uma prova.
2. Resolva sem consultar o gabarito.
3. Compare sua solucao com o gabarito.
4. Revise os pontos fracos e registre os ajustes.

## Fluxo de estudo (Maria + Manuela)
1. Cada uma resolve a prova.
2. Cada uma revisa a resolucao da outra.
3. Os ajustes ficam registrados no repositorio.

## Como adicionar nova prova
1. Crie um arquivo no padrao: prova_XX_tema.md ou prova_XX_tema.pdf.
2. Inclua:
   - Enunciado das questoes
   - Tempo sugerido
   - Criterios de avaliacao
   - Gabarito (no final ou em arquivo separado)
